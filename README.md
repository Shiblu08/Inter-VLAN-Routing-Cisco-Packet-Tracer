# Inter-VLAN Routing using Cisco Packet Tracer

## Overview
This project demonstrates Inter-VLAN Routing using Router-on-a-Stick.

## Features
- Created VLAN 10 (Sales) and VLAN 20 (HR)
- Configured Access Ports
- Configured 802.1Q Trunk
- Implemented Router-on-a-Stick
- Verified connectivity using Ping

## Technologies
- Cisco Packet Tracer
- Cisco IOS
- VLAN
- TCP/IP
- Router-on-a-Stick
